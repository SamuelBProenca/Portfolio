# Modelo do questionário de projetos

Este é o conteúdo para criar o formulário na sua conta do Google. O formulário ainda não foi criado ou publicado. O portfólio está preparado para receber o link público; enquanto ele não existir, o contato por e-mail continua disponível.

## Título

Vamos entender seu projeto

## Descrição

Conte o que você precisa construir, o que já existe e qual problema quer resolver. Estas respostas ajudam Samuel Proença a entender sua necessidade antes da conversa.

Para recrutamento e outros contatos profissionais, envie um e-mail para samuelbrito782@gmail.com.

## Pergunta 1

**O que você precisa desenvolver?**

Tipo: múltipla escolha. Obrigatória.

- Uma aplicação web
- Uma API ou integração entre sistemas
- Uma automação de processo
- Melhorias em um sistema existente
- Ainda preciso de orientação

## Pergunta 2

**Em que estágio está o projeto?**

Tipo: múltipla escolha. Obrigatória.

- Estou explorando a ideia
- Já tenho um escopo ou requisitos
- Já existe um sistema em uso

## Pergunta 3

**Qual problema você precisa resolver?**

Tipo: parágrafo. Obrigatória.

Descrição da pergunta:

Explique o que acontece hoje, o que você gostaria de melhorar e quais são as principais dificuldades. Não precisa usar termos técnicos.

## Pergunta 4

**Qual e-mail ou WhatsApp posso usar para retornar?**

Tipo: resposta curta. Obrigatória.

Descrição da pergunta:

Informe um e-mail ou um número com DDD. Esse contato será usado para conversar sobre sua solicitação.

Não aplique a validação exclusiva de e-mail a esta pergunta, pois ela também aceita WhatsApp. Esse campo permite retornar mesmo quando a pessoa preenche o formulário e sai sem abrir a conversa.

## Mensagem de confirmação

Texto para colar:

```text
Suas respostas foram registradas. Obrigado por contar sobre seu projeto!

Se quiser continuar a conversa pelo WhatsApp, use este link:
https://wa.me/5519989587907?text=Ol%C3%A1%2C%20Samuel!%20Enviei%20o%20formul%C3%A1rio%20de%20projeto%20do%20portf%C3%B3lio%20e%20gostaria%20de%20continuar%20a%20conversa.

O envio da mensagem é confirmado por você no WhatsApp.
```

**Nota para configurar:** o link acima abre uma mensagem fixa. Ele não transfere automaticamente as respostas do Forms para o WhatsApp; elas ficam na aba Respostas do formulário. Confira a apresentação e o acesso ao link na confirmação depois de criar o formulário.

## Configuração e publicação

1. Crie um formulário em branco no [Google Forms](https://forms.google.com/), usando o título, descrição e quatro perguntas acima.
2. Mantenha **Limitar a 1 resposta** desativado para não exigir login por essa opção. Disponibilize o formulário para qualquer pessoa com o link, incluindo quem não está conectado a uma conta Google.
3. A pergunta de retorno já coleta o contato informado pela pessoa; não é necessário exigir coleta de e-mail verificado ou upload de arquivos.
4. Mantenha **Ver resumo dos resultados** desativado, para que os visitantes não vejam as respostas de outras pessoas.
5. Em **Apresentação**, substitua a mensagem de confirmação pelo texto acima.
6. Na aba **Respostas**, ative as notificações por e-mail de novas respostas, se desejar acompanhar as solicitações. Vincular a uma planilha é opcional.
7. Publique o formulário e copie o **link para responder**. Teste em uma janela privada: perguntas, ausência de exigência de login, envio e confirmação.
8. Envie o link público neste chat. Use o endereço `forms.gle/...` ou `docs.google.com/forms/d/e/.../viewform`, não o link terminado em `/edit`.

Após conectar o link, o portfólio oferecerá **Descrever meu projeto** para solicitações de projeto e o e-mail direto para recrutamento. O número de WhatsApp não será exibido na seção do site.

Referência: [publicar, compartilhar e configurar o Google Forms](https://support.google.com/docs/answer/2839588?hl=pt-BR).
