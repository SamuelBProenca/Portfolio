# Samuel Proença — Portfólio

Portfólio pessoal em Next.js e TypeScript. O aplicativo atual fica em **`portfolio/`**.

```sh
cd portfolio
npm ci
npm run dev
```

No Vercel, selecione **Root Directory: `portfolio`**, framework Next.js e Node.js 22.x. Consulte [o guia de publicação e contato](portfolio/docs/DEPLOYMENT.md) antes de configurar o formulário.

Execute `npm run check` e `npm run build` dentro do app. O workflow em `.github/workflows/ci.yml` também verifica o navegador em produção.

A versão anterior foi preservada em `legacy/pre-rework/portfolio/` para referência. Ela não é o aplicativo publicado.
